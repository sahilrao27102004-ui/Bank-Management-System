# Bank Account Management System

## About the Project
This is a beginner level Python project that I made to practice my Python programming skills and learn how a bank account system works.

In this project, users can manage their bank accounts using a simple menu in the terminal. I have used Python classes, inheritance, functions, loops, and conditional statements to build this project.

## Features
- **Debit Amount:** Withdraw money from the account.
- **Credit Amount:** Deposit money into the account.
- **Check Balance:** Check the available account balance.
- **Calculate Interest:** Add 5% interest to the savings account. Interest can be calculated only once per account.
- **Transaction History:** View the debit, credit, and interest transactions.
- **Create Account:** Create a new savings account with a fixed 5% interest rate.
- **Change Account:** Switch between existing accounts without restarting the program.
- **Input Validation:** Handles invalid inputs and checks for insufficient balance.

## How to Run the Project

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python editor.
4. Run the Python file using this command:

   ```bash
   python bank.py
   ```

   Replace `bank.py` with your actual Python file name if it is different.
